# vibator.dev

The [vibator.dev](https://vibator.dev) website, built with
[VitePress](https://vitepress.dev). It documents
[vibator](https://github.com/vibator/vibator), the quality gate framework
for coding agents, and [the gate](https://github.com/vibator/gate), the
shared configuration presets that projects extend.

## Contributing

See [CONTRIBUTING.md](./CONTRIBUTING.md). The repository is gated by
[@vibator/gate](https://github.com/vibator/gate): `npm run verify` runs
everything CI runs.

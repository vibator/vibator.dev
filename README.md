# vibator.dev

The [vibator.dev](https://vibator.dev) website, built with
[Astro](https://astro.build). It documents
[vibator](https://github.com/vibator/vibator), a small framework for project
rules over JavaScript and TypeScript projects. The docs come from the vibator
repository, one version per release from 3.0.0 on.

## Contributing

See [CONTRIBUTING.md](./CONTRIBUTING.md). Participation is governed by the
[Code of Conduct](./CODE_OF_CONDUCT.md). Commits follow Conventional Commits.
[ACCESSIBILITY.md](./ACCESSIBILITY.md) says what the site does for accessibility,
how it is checked, and how to report a barrier.

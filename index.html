What is Vibator?
GitHub
  • 🧩

    Unopinionated

    Vibator ships no rules of its own. It gives you the utilities to turn your own standards into actionable checks.

    Why Vibator

  • ✍️

    Highly customizable

    Rules are plain JavaScript or TypeScript, with no DSL or pipeline to learn. When a rule runs, you control what its diagnostics look like.

    Getting started

  • 🤖

    Integrates with coding agents

    Ships with agent skills, and a rule links to a guideline, so an agent has the detail it needs to act on a finding.

    Agent skills

  • 🔌

    SARIF compatible

    Drop Vibator into the code-scanning and CI workflows you already run.

    Reporters

Add it to a project ​

sh
$ npm install --save-dev vibator
sh
$ pnpm add -D vibator
sh
$ yarn add -D vibator
sh
$ bun add -d vibator

Vibator ships no rules of its own. Scaffold a .vibator.json and start writing them:

sh
$ npx vibator init
